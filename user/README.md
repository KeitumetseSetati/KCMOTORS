# KC Motors Web Inventory System

A web-based application designed to manage vehicle or product inventory for KC Motors. The system provides a user-friendly interface for adding, updating, deleting, and searching products, as well as generating reports. Built as a practical project to demonstrate full-stack web development skills.

## Features

- **Product Management**:
  - Add new vehicles/products with details (name, model, price, quantity, etc.)
  - Update existing product information
  - Delete products from the inventory
  - Search for products using keywords
- **Inventory Reporting**:
  - View all products in a structured grid or table
  - Highlight items that are running low
- **Responsive Web Interface**:
  - Easy-to-navigate layout
  - Mobile-friendly design
- **Interactive Forms**:
  - Form validation to ensure accurate data entry

## Technologies Used

- **Front-End**:
  - HTML5
  - CSS3
  - JavaScript
  - Bootstrap (for responsive design)
- **Back-End**:
  - Node.js
  - Express.js (server framework)
  - Database integration (e.g., MongoDB or MySQL) for storing product information
- **Tools**:
  - Visual Studio Code
  - Browser for testing (Chrome, Edge, Firefox)
